
# ITB_Siege

**A mod for Subset Game's _[Into the Breach](https://subsetgames.com/itb.html)_**

**Features :**
* 1 new squad
* 3 new mechs
* 3 new weapons

**Requires [ITB-ModLoader v2.9.5](https://github.com/itb-community/ITB-ModLoader/releases) or later.**
